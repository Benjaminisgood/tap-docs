场景

这些是这份程序已经对应的用法。挑一个开始，做完再加下一项。

在自己的电脑上看数据​

装好之后运行 taptaptap webui，浏览器打开 http://127.0.0.1:8888。先发一句「你好」。有回复之后，把一份 WYX 放进工作区，请它读出质量数和脉冲数。

看完这一步： 把第一份数据交出去。

和助手一起填参数​

在右侧工作台打开定量分析或动力学分析，检查每步的输入、配置和输出，创建运行并审查节点。需要自己的分支与汇合时，打开 DAG 工作流，在画布空白处双击添加命令，再连接步骤。连线控制执行先后，文件路径仍由你明确填写。

看完这一步：工作台与分析流程。

多个话题协作​

把相关话题放进同一组，并排看各自的聊天和工作台标签。每个标签保留所属话题的项目与权限；Agent 修改参数时与你编辑同一份版本化草稿，冲突需要复核。

看完这一步：协作与恢复。

在终端里接着同一段话​

另开一个终端运行 taptaptap。用 /sessions 打开浏览器里那段话题。两边看到同一次回复，工作只做一次。

看完这一步： 终端。

先用仿真把实验走一遍​

仪器页面默认关着。打开之后，把后端留在 sim，请它按实验步骤做一次预演，并告诉你写出了哪些文件。Mac 和 Linux 上可以这样走完目录结构。

看完这一步： 仪器。

在实验室电脑上操作真机​

后端改为 windows 之后，网页里的 PID、TAP、QMS、Quantitative、Process Value 和 Program 才对着实验室那台装置。同一台仪器不要同时开两处控制。

两个人各用各的​

每个人一份配置、工作区和网页地址。不要共用同一个配置文件。
