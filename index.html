实验室里的 TAP 助手。浏览器和终端都能用。

装在你自己的电脑上。先配好一个模型，发出一句「你好」，再把 WYX 和实验文件夹交给它。

推荐安装

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
taptaptap onboard
taptaptap webui

在这份项目的文件夹里执行。需要 Python 3.12 或更新版本。安装结束后浏览器打开本机页面。
