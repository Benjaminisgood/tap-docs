命令行

这些命令在系统终端里运行，不是对话输入框里的 / 命令。对话里的命令见 对话里的命令。

先激活安装时的 .venv。用 taptaptap --help 查看当前安装的入口，再用相应子命令的 --help 查看选项。taptap 是科学命令行，taptaptap 是 Agent 和服务入口，两者不要混用。

最常用​

命令作用
taptaptap --version看版本
taptaptap onboard生成或更新配置和工作区
taptaptap onboard --wizard用问答来填配置
taptaptap onboard --refresh保留已有设置，补上新字段
taptaptap status看配置、工作区和模型是否就绪。不呼叫模型
taptaptap webui打开浏览器工作台
taptaptap打开全屏终端
taptaptap agent -m "你好"发一句后退出
taptaptap --classic逐行终端
taptaptap gateway --background把服务留在后台
taptaptap gateway status后台是否在跑
taptaptap gateway logs看后台输出
taptaptap gateway stop停下后台
taptaptap gateway restart重启后台
taptaptap serve打开给其他程序用的本机接口，需要 api 可选依赖

常用的附加项：

附加项作用
--workspace 或 -w支持该选项的子命令指定工作区文件夹
--config 或 -c支持该选项的子命令指定另一份配置文件
agent --session 或 agent -s终端继续某一段对话
agent --theme auto|dark|light全屏终端的深浅色

配置和工作区选项放在对应子命令后。管理同一个实例时沿用启动时的配置和工作区参数，例如：

taptaptap webui --config /absolute/tap-instance/config.json --workspace /absolute/project
taptaptap gateway status --config /absolute/tap-instance/config.json --workspace /absolute/project

直接输入 taptaptap、taptaptap webui 时，如果发现正在运行的 Desktop，会让你选择 Desktop 或当前 Python 环境。taptaptap agent 或带显式选项的调用使用当前 Python 环境。

端口与前端更新​

入口默认端口覆盖选项
浏览器 WebUI8888taptaptap webui --port 8889
网关健康与管理监听18888taptaptap webui --gateway-port 18889，或 gateway --port
程序调用 API8900taptaptap serve --port 8901

端口也可能由已有配置改写，启动输出是实际值。多个实例还需要分别配置目录和工作区，见 多份实例。

taptaptap webui --dev 用 Vite 开发服务器更新前端；--no-open 只取消自动打开浏览器。源码更新后，普通 webui 会检查前端构建，已有网关还需重启才能加载后端代码。

提供商、渠道和可选功能​

命令作用
taptaptap provider login按提示登录一家提供商
taptaptap provider logout登出
taptaptap channels status看聊天平台是否连上
taptaptap channels login 名字登录列表里已有的平台
taptaptap plugins list看可选功能
taptaptap plugins enable 名字启用一项
taptaptap plugins disable 名字停用一项
taptaptap trigger 名字 "一句话"向已登记的本地触发送一句话

文件转换和可选同步也有独立入口，先查帮助再填实际路径：

taptaptap wyx-sqlite --help
taptaptap ods --help
taptaptap lan-transfer --help
taptaptap syncthing --help
taptaptap remote --help

mac-transfer 是 lan-transfer 的弃用别名。同步和传输命令不承担科学分析。科学命令的输入、输出和参数以当前 taptap catalog 为准：

taptap --describe-json

开机即用​

taptaptap gateway install-service --dry-run
taptaptap gateway install-service
taptaptap gateway uninstall-service

--dry-run 只打印将要安装的内容。这条面向 macOS 和 Linux。说明在 一直开着。

会话文件夹​

对话记录在配置对应的会话目录里，默认是 ~/.taptaptap/sessions/<工作区标识>/。工作台与流程状态也保存在实例数据中。换工作区不会把这些记录搬进实验文件夹，也不会自动授予对其他对话的修改权限。

taptaptap sessions restore-workspace --help

需要把某段对话指回一个工作区时，先看这条帮助再执行。执行前确认路径是你要的那个实验文件夹。
