技能

技能是一段工作说明：遇到这类实验任务时先核对什么、结果交到哪里、哪些话还不能当成结论。你不需要背内部名字。用 任务指南 里的说法开口，它会选用对应的说明。

在哪里开关​

浏览器侧栏 Skills（技能），或 Settings → Capabilities（设置 → 功能） 里的技能页。

  • Installed（已安装） 列出当前工作区能用的技能。
  • 搜索框按名字或说明过滤，也可以只看已启用或已停用项。
  • 点击技能，在当前列表页打开详情面板；不会创建新对话，也不会打开工作台标签。
  • 开关打开并且条件满足时，它才会按那份说明工作。
  • Needs setup（需要设置） 表示还缺本机程序或环境变量。依赖有安装说明时可以复制命令，补齐后点 Check again（重新检查）。

终端里输入 /skill 列出当前启用的技能。

查看和修改说明​

详情显示来源、启用状态、依赖与完整说明。允许编辑的技能显示 SKILL.md 文本框；修改后点 保存 写入文件。放弃修改 恢复当前已读取内容，从文件重新加载 加载文件的最新内容。只读技能只展示原文。

保存会检查文件是否被其他窗口改过。出现冲突时，先保留需要的草稿，再重新读取并核对。详情编辑并非自动保存，离开前应完成保存。

随程序带上的几类​

你说的事它按哪类说明做
看看 WYX、列质量数和脉冲查看，不改文件
汇总成表或导出 CSV按你说的范围写出新文件
留下一部分脉冲并重新编号先给你看范围，再复制到新目录
基线漂不漂只做基线诊断
面积和相对面积用你接受的基线和内标
脉冲量用你给出的压力单位和气路
质量校准先证据，你接受之后才改配置
Y 方法、速率、浓度、积累进料、脉冲量和内标要明确
扩散、Knudsen、温度关系窗口和质量数要明确
转化、选择性、元素平衡用已经核对的面积和脉冲量
准备或启动一次实验实验文件、输出目录，以及仿真还是真机
看仪器现在的读数先打开仪器页面，并且知道是哪一台
参数很多、要你点头再跑在工作台共同填写 TAP 命令参数，并按版本批准
把已有的 WYX 收成一个 SQLite 文件只打包已经写好的脉冲，不重做定量

从 Skillshub 安装​

已安装 / Skillshub / 第三方市场 是技能页的三个标签。中间的 Skillshub 从门户的公开库与当前账号的个人库加载真实目录，支持搜索、筛选、预览和选择下载。下载后保存在当前工作区 skills/<name>/，回到 已安装 后沿用现有编辑、开关和删除入口；同名安装不会覆盖本机内容。来源筛选不改变可见性或编辑权限。

从第三方市场安装​

技能页的外部市场继续提供 skillhub.cn 和 skills.sh 搜索与安装。它们是第三方服务，与内部 Skillshub 无关。安装前页面会请你确认来源。只安装你认得、并且确实需要的那一个。

删掉一份技能，会从当前工作区移除它的文件。随程序自带的实验技能，关掉开关即可。

和自动任务的差别​

技能决定这类事怎么做。自动任务决定什么时候再做一次。定时在侧栏 Automations，见 自动任务。

技能也不等于应用页面或运行任务。应用入口见 应用与技能，共同编辑和执行见 工作台与分析流程。
