介绍

先让助手在浏览器里正常回复，再按下一件要做的事打开对应的一章。写程序、改界面时再看仓库里的内部说明。使用这份程序不必先读那些文件。

本手册跟随 TAP 的 cursor 开发线。最近一次功能核对为 2026-10-25，以 ff9d2adc 为起点并包含本轮升级；范围见 版本与更新。用 taptaptap --version 看包版本，源码安装再用 git rev-parse --short HEAD 确认提交；同一个包版本可能包含不同的开发提交。

界面默认是英文。侧栏 Language（语言） 可以改成简体中文。下面第一次提到按钮时，先写屏幕上的英文，括号里是中文界面的名字。

先看你的情况​

你的情况读这一章做完的标志
终端、Python 或密钥还不熟零基础浏览器发出「你好」并收到回复
你习惯自己敲命令快速开始taptaptap status 就绪，网页或终端能收到一句回复
已经失败了遇到问题能分清是安装、配置、模型、后台、聊天平台，还是文件权限

建议的第一次：

  1. 在项目文件夹里安装。
  2. 运行 taptaptap webui，在这台电脑上打开浏览器。
  3. 在 Settings → Models（设置 → 模型） 里配好提供商和模型。
  4. 先发送「你好」，再交实验数据。

多数人第一次不必手改配置文件。网页负责模型、密钥和本机页面。已经有配置、没有图形界面，或向导更顺手时，用 taptaptap onboard --wizard。网页打开之后：模型在 Settings，聊天平台在 Channels（聊天平台），本地程序在 Apps（应用）。

查阅配置时​

设置页能改的，优先在设置页改。手册里出现的配置片段是要合并进 ~/.taptaptap/config.json 的一小段，不是整份替换文件。密钥、密码不要贴进对话，也不要贴进发给别人的记录。
