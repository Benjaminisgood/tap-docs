零基础

这一章不假设你会配环境。做完时，浏览器里已经发出「你好」，并且收到回复。

你需要准备什么​

  • 一台 macOS、Windows 或 Linux 电脑。
  • 保存着这份 taptaptap 项目的文件夹。
  • 一家模型服务的密钥，或一台你自己的模型地址。密钥向提供模型的那一家申请。
  • 大约能看懂「把这段文字粘进终端」。

同事如果已经给你网页地址和密码，直接打开那个地址，从 快速开始 的「配一个模型」继续。

几个词​

词意思
终端电脑上输入文字命令的窗口。macOS 叫终端，Windows 可以用 PowerShell
Python运行这份程序的语言环境。需要 3.12 或更新版本
虚拟环境一个单独的小房间，避免和电脑上别的 Python 程序混在一起。文件夹名叫 .venv
密钥模型服务发给你的一串密码。只填在设置里
工作区这次对话用来放实验文件的文件夹
模型真正写回复的那一个服务。taptaptap 负责把你的话送过去，并把实验文件留在本地

1. 安装 Python​

打开终端，输入：

python3 --version

Windows PowerShell：

py -3.12 --version

版本号需要是 3.12 或更高。看不到这条命令时，先从 Python 官网安装 3.12，关掉终端再开一次，然后重试。

2. 准备模型资料​

先放在一边，装完再填。你需要这三样里的适用项：

  • 提供商的名字，例如你申请密钥的那一家。
  • 密钥。
  • 如果是公司或自己的服务器，还要服务地址。本机的 Ollama 通常不要密钥，要本机地址。

3. 安装 taptaptap​

用终端进入项目文件夹。路径按你电脑上的实际位置来。

macOS / Linux：

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
taptaptap onboard

Windows PowerShell：

py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
taptaptap onboard

行首出现环境名字，说明这个终端已经在用这次安装。下次新开终端，要再执行一次 source .venv/bin/activate 或 .venv\Scripts\Activate.ps1。

onboard 第一次会写出配置。它问要不要覆盖时，选保留现有内容。

4. 在网页里配置模型​

taptaptap webui

浏览器打开 http://127.0.0.1:8888。让这个终端保持开着。

  1. 点 Configure model（配置模型），或打开 Settings（设置）→ Models（模型）。
  2. 打开 Configure providers（配置提供商），填入密钥，或按页面按钮登录。
  3. Add configuration（添加配置），起一个你认得的名字，选主模型，保存。
  4. 如果页面说要重启，用设置页的重启按钮，或在那个终端按 Ctrl+C 后再运行 taptaptap webui。

5. 第一句回复​

在输入框发送：

你好

Enter 发送。出现一段正常回复就完成了。

6. 一次只加一件事​

回复成功之后，只加一项，例如 把第一份数据交出去 或 打开终端。不要同时改模型、开仪器、接聊天软件。

失败了怎么办​

回到 遇到问题，按表从上往下看。一次只改一条。

下次怎么打开​

新开终端，进入项目文件夹，激活 .venv，然后：

taptaptap webui

只想用终端时：

taptaptap
