快速开始

这一页的目标只有一个：浏览器里出现一句正常回复。做到之前，不要接聊天平台、定时任务或仪器页面。

终端、Python 或密钥还不熟时，先看 零基础。

需要什么​

  • Python 3.12 或更新版本。
  • 从源码启动网页时，需要 Bun 或 npm 来构建前端；全屏终端使用 Bun 1.4.0。已打包的客户端按其发行说明安装。
  • 一家模型服务，或你自己的模型地址。
  • 这家服务要求的密钥、地址和模型名字。本机 Ollama 往往只要地址。

1. 安装​

在 TAP 仓库根目录里（能看到 pyproject.toml、tap/、taptap/ 和 taptaptap/）。当前开发线是 cursor，稳定线是 main。首次获取开发线：

git clone --branch cursor https://github.com/Benjaminisgood/TAP.git
cd TAP

已有检出先确认本地修改，再更新当前开发线：

git status --short
git branch --show-current
git pull --ff-only origin cursor

这里应显示 cursor。有未处理修改、分支不符或不能快进时，先处理该状态，保留自己的文件。

macOS / Linux：

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
taptaptap onboard
taptaptap webui

Windows PowerShell：

py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
taptaptap onboard
taptaptap webui

首次启动会检查网页构建；缺失或过期时，按提示构建。浏览器默认打开 http://127.0.0.1:8888，实际地址以终端输出为准。这个默认地址只给这台电脑。让运行 taptaptap webui 的终端保持打开；单独关闭浏览器不会停止服务。

如果已经运行 Taptaptap Desktop，直接输入 taptaptap 或 taptaptap webui 可能出现目标选择。要核对这份源码，选择当前 Python 环境；显式运行 taptaptap webui --no-open 则使用当前环境，再打开打印的地址。

已有配置时，onboard 会问是恢复默认，还是保留现有内容并补上新字段。第一次选保留。

2. 配模型​

Settings → Models（设置 → 模型）：

  1. 在提供商里填入密钥或完成登录。
  2. 新建一个预设，选择主模型，保存。
  3. 页面要求重启时，重启后再回来。

密钥写在设置里，不要贴进对话。

3. 看本机状态​

另开一个已激活环境的终端：

taptaptap status

希望看到 Config、Workspace 有勾，Model 是你刚选的，Agent 说明提供商和模型已经就绪。其余提供商显示 not set 是正常的。这条命令不呼叫模型。

4. 发出第一句​

回到浏览器，发送：

你好

有正常回复，就说明配置能读到、模型能连上、工作区可用、网页也能打开。

只用终端确认​

taptaptap agent -m "你好"

然后进入全屏：

taptaptap

从这份项目启动全屏界面时需要 Bun 1.4.0。起不来就用 taptaptap --classic。细节在 终端。

装好之后文件在哪​

位置里面是什么
~/.taptaptap/config.json模型、界面和运行设置
~/.taptaptap/workspace/默认工作文件夹
~/.taptaptap/sessions/<工作区标识>/对话记录、工作台布局和工作流状态，放在工作文件夹外面
~/.taptaptap/command-operations/、~/.taptaptap/tap-runs/CLI 操作与实际运行记录

指定 --config 后，实例数据随配置文件所在目录存放。配置目录应在实验工作区之外；不同 TAP、TPX、TAK 实例分别使用自己的配置、工作区和端口。

下一件只做一件​

目标去这里
熟悉网页浏览器工作台
熟悉终端按键终端
与 Agent 共同编辑应用和流程和 Agent 协作
换模型或加备用提供商和模型
交一份 WYX把第一份数据交出去
看仪器仪器

第一句失败时​

taptaptap --version
taptaptap status
taptaptap agent -m "你好"

然后打开 遇到问题。一次只改一件事。
