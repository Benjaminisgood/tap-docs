浏览器工作台

打开​

taptaptap webui

浏览器进入 http://127.0.0.1:8888。让这条命令所在的终端保持打开。默认只有这台电脑能打开。

前十分钟​

  1. 确认输入框上的模型是你要用的那个。
  2. 点 New topic（新建话题）。
  3. 发送一句短话，确认有回复。
  4. 用 Attach files（添加文件） 带上一张小图或一个小文件。
  5. 再把实验文件夹指给它。见 把第一份数据交出去。

它适合做什么​

看 WYX、按你给出的条件做定量和作图、整理实验文件，以及在你打开仪器页面后查看实验台。它把候选、依据和异常放在你面前。采不采用，见 由你验收。

话题​

左侧栏：

屏幕上的名字做什么
New topic（新建话题）新开一段对话，原来的还在历史里
Search（搜索）按文字找话题。没有结果时显示 No matching topics
Recent topics（最近话题）点开接着聊
Apps（应用）安装、启用和配置应用；打开应用进入所属对话的工作台
Automations（自动任务）以后再做的事，以及日历
Skills（技能）在详情面板查看、开关或编辑某一类工作的说明
Bench（仪器台）温度、流量、质谱和实验程序。默认不出现
Settings（设置）模型、外观、系统

侧栏可以收起。窄屏幕上这些入口收进菜单。

点一条你说过的话可以跳回去。从历史回复分出的新话题会标出来源，原来的话题保持原样。

右上角能看到这个话题关联的自动任务：下次何时运行，或是否已暂停。

过程和用量​

回复里可以展开做过的步骤。看不清时点 View activity（查看过程）。

输入框附近的百分比是这段对话占了多少上下文。点开可以看到最近几轮的输入、输出和缓存命中。某一轮没有报上来时，图上留空，不会把它算成零。

临时聊天​

Temporary chat（临时聊天） 不写入历史，也不写入记忆。刷新、关闭页面或连接断开后，这段聊天结束。

发给模型的请求仍然会发出去。它如果改了文件，那些修改会留下。正式的数据处理放在普通话题里。

工作区和权限​

输入框上方可以选择项目，以及这次对话的权限。

屏幕上的名字含义
Default Permission（默认权限）按这个项目已有的权限工作，通常只处理当前工作文件夹
Full Access（完全访问权限）可以碰到工作文件夹以外的路径。只在你清楚要读或改哪些文件时使用

默认文件夹在 ~/.taptaptap/workspace。终端若在实验文件夹里启动，那次对话用那个文件夹。更多说明在 概念。

输入框​

空话题的提示是 Describe a TAP task or WYX dataset...（描述 TAP 任务或 WYX 数据集...）。

  • Enter 发送，Shift+Enter 换行。
  • Choose a model（选择模型） 只改这段对话的预设。全部预设在 Settings → Models。
  • 回复进行中可以按 Stop response（停止响应）。
  • 还没回复完就继续打字，内容会排成 Waiting to send（等待发送），可以改顺序或删掉。
  • 输入 / 列出 对话里的命令。方向键移动，Tab 补全，Esc 关闭。
  • 输入 @ 提到已安装的应用、MCP 服务，或一段过去的对话。

长对话可以用 /compact 收成摘要。对话还在，更早的原文会折进去。摘要里没写上的数字，下一轮未必还在。

聊天平台​

浏览器和终端是默认的两个入口。别的聊天软件在 Settings → Channels（聊天平台）。见 聊天平台。

应用​

Apps（应用） 管理可调用的程序、插件、连接和应用前端。部分应用可以在对话里用 @ 提到；有页面的应用通过「打开」进入聊天旁的工作台。

从 Apps 打开应用会创建并进入一个以应用命名的新对话；工作台标签栏的 + 在当前对话中增加应用。没有独立的工作台侧栏页，也没有第二套项目和权限选择。

多标签工作台​

工作台可以同时打开 定量分析、动力学分析、DAG 工作流、文件与 OSS 和已启用的文献、仪器应用。切换标签保留编辑器；刷新恢复仍打开的标签，已关闭的标签不会被旧的待填任务重新打开。

你和 Agent 可以共同填写参数。固定分析应用按步骤创建运行、逐项审查批准；DAG 可以添加命令节点、连接分支、编辑参数及导入导出。运行使用独立版本快照，修改草稿不改旧运行。

关闭标签不等于取消任务。操作方法见 工作台与分析流程；Papis、OSS 和应用管理见 应用与技能。

技能​

Skills（技能） 是某一类实验工作的说明：先核对什么、结果写到哪里。点击技能会在列表页弹出详情，可以开关、检查依赖，并编辑允许修改的说明；这个操作不会创建聊天或打开工作台。开关打开并且条件满足时，Agent 才会按那份说明做。名字不必背，用 任务指南 里的说法开口即可。细节见 技能。

自动任务​

侧栏 Automations（自动任务） 用来安排以后再做的事。时区在 Settings → System（系统）。见 自动任务。

设置​

点 Settings，左上角箭头是 Back to chat（返回聊天）。

分区你来这里做什么
Overview（概览）当前模型、已配置的提供商、工作区、近一段时间用量
Appearance（外观）浅色或深色、回复过程默认展开多少、是否在页面退到后台时通知
Models（模型）预设、主模型和备用模型
Capabilities（功能）技能、自动任务、应用、网页搜索、图片、语音、聊天平台
System（系统）时区、默认工作区、默认权限
Advanced（高级）搜索后才会改的运行选项。不确定时保持原样
About（关于）版本、检查更新，以及连接 GitHub。源码隔离包装里没有会写入私有仓库令牌的 GitHub 登录

语言在侧栏 Language，记在这台浏览器里。外观也可以用页面顶部的按钮切换。

改完如果按钮变成等待重启，先保存，再重启。重启完成前，页面上仍是旧设置。

手机和主屏幕​

页面在这台电脑的浏览器里。如果浏览器提供安装或添加到主屏幕，打开的仍是 http://127.0.0.1:8888。手机不在这台电脑上时，加到主屏幕也到不了这个地址。

局域网​

默认地址只给本机。要让另一台电脑打开，用 一直开着 里的方式，并为需要对外的入口设置密码或密钥。不要把没有密码的页面直接暴露到网络上。

排错​

网页打不开、要密码、或模型未配置时，看 遇到问题。
