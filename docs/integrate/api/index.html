从其他程序调用

平时看数据和做实验，用浏览器或终端。这一页是给另一个程序来问同一份 taptaptap 时用的。

打开​

在已经激活的环境里：

taptaptap plugins enable api
taptaptap serve

第一条安装 API 所需的可选依赖；已经装好时无需重复。源码安装也可以用 python -m pip install -e '.[api]'。

默认地址：

http://127.0.0.1:8900/v1/chat/completions

终端会打印实际的地址、当前模型和超时时间。默认监听 127.0.0.1:8900，单次执行超时为 120 秒。另一个程序把请求发到这个地址，用的是你已经配好的模型预设。自定义实例沿用自己的配置和工作区：

taptaptap serve --config /absolute/tap-instance/config.json --workspace /absolute/project --port 8901 --timeout 300

让别的机器也能连时，必须先设置 API 密钥。没有密钥就绑定到整台机器的网络上，程序会拒绝启动。密钥和网页密码一样，不要写进仓库或对话。

发出请求​

路径用途
GET /health服务健康检查，不呼叫模型
GET /v1/models返回当前配置模型的名字
POST /v1/chat/completions在 API 会话里发送一条用户消息

默认本机、未配置 API 密钥时，可以这样试一次；最后一条会实际调用模型：

curl http://127.0.0.1:8900/health
curl http://127.0.0.1:8900/v1/models
curl http://127.0.0.1:8900/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"messages":[{"role":"user","content":"你好"}],"session_id":"demo"}'

每次 messages 只接受一条 role: "user" 消息，历史由服务端保留。省略 session_id 使用 api:default；指定 demo 则使用 api:demo。同一会话的请求依次执行，多个调用方要隔离历史时应使用不同的会话标识。

model 可以省略；传入时必须与 /v1/models 返回的当前模型一致，不能借此切换任意模型。JSON 请求设置 "stream": true 可接收 SSE，结束标记为 data: [DONE]。这是一组有限的 OpenAI 兼容接口，不提供所有 OpenAI API 路径或任意客户端历史重放。

认证​

在现有配置中合并 api 字段，不要用下面片段替换整份模型配置：

{
  "api": {
    "host": "127.0.0.1",
    "port": 8900,
    "timeout": 120,
    "apiKey": "替换成你生成的私有随机密钥"
  }
}

配置 apiKey 后，/v1/models 和 /v1/chat/completions 都要求 Authorization: Bearer <密钥>；/health 保持可直接检查。这里使用 API 专用密钥，不是模型提供商密钥或网页密码。将监听改为非本机地址时必须有密钥，并由部署环境提供适当的网络访问控制。

和网页的差别​

网页这个接口
地址http://127.0.0.1:8888http://127.0.0.1:8900/v1/chat/completions
谁在用你自己看话题、文件和设置另一个程序发来一句并取回回复
会话你在侧栏里点的话题api:default 或请求指定的 api:<session_id>

网页上的仪器按钮、话题列表和设置不在这个地址上。

关掉​

在运行 taptaptap serve 的终端按 Ctrl+C。网页如果是单独开的，不会一起关掉。

接口返回了文字，只说明模型回了一段话。实验数字仍以工作区里的文件为准。
