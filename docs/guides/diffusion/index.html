扩散

这一页包括三件可以分开做的事：比较测到的扩散响应、看 Knudsen 响应、以及温度关系。每一件都要写清窗口、质量数，以及要比较的是哪一次测量。

可以怎么说​

比较 Measurement/sample 和 Measurement/reference 的扩散响应。
质量数用 40。时间窗口用我实验记录里的那一段。
结果写到 results/diffusion-compare。窗口不够明确就停下来。
对 Measurement/run12 做 Knudsen 响应。内标是 m/z 40。先给报告，不要改别的配置。
用已经算好的 results/diffusion 做温度关系。只使用我标出的那几个温度点。把不确定度写出来。

已有的扩散结果只需要画图时，说明不要重算，并给出已有文件的路径。

你要看的​

  • 参比床和样品是不是你指定的那两个目录。
  • 窗口没有被扩到你没同意的时间段。
  • 内标和质量数。
  • 温度关系里点了哪些温度，不确定度有没有写上。
  • 拟合曲线只覆盖你给出的区间。

这些图和报告是诊断。它们不代替你决定这个模型是否适用于这个反应器。
