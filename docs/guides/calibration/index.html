质谱校正

在工具列表打开「质谱校正」。它与定量分析、动力学分析同级，在独立浏览器标签中运行，不依赖对话或工作台。

准备数据和配置​

  1. 创建一个项目，导入已有 TOML 或修改示例配置。示例中的物种、AMU、标气比例和初始系数仅说明格式，须替换为本次实验参数。
  2. 上传含 WYX 的目录，或点击 浏览服务器目录，从当前账号的工作文件中选择目录，无需填写服务器路径。输入文件会复制到本工具项目，目录层级保留。TOML 中的路径相对于本项目输入根目录，不能指向其他项目或任意服务器路径。
  3. 保存配置并检查输入。calibration.species 的顺序就是扫描顺序；每个实验目录名必须对应 mass_calibration.gas_mixtures 的 experiment_id。

例如，配置 data_root = "data" 和 experiment_id = "mixture-example" 对应上传后的 data/mixture-example/*.wyx。选择 data 文件夹上传时，保留这个文件夹名。基线目录和可选参考状态 CSV 也放在输入根目录下，并在配置中写相对路径。

每份标准气配置需要明确参比物种、各组分比例、用于求响应系数的物种、碎片来源及观测通道。页面不会猜测气体组成或调整扫描顺序。

选择面积来源​

  • baseline_aware_signal：按完整信号和配置的 baseline_sources 拟合、扣除基线后积分。需要实际基线 WYX 数据。
  • wyx_header_area_values_vs：读取 WYX 头部指定 area_index 的积分面积，并乘每个文件自身的放大器灵敏度转换为电荷。此模式不再次拟合基线。

支持已有的 direct_ratio 和 reference_subtracted_fixed_point 碎片学习方法；保留初始矩阵中的冻结单元 "F"。配置校验沿用原处理脚本，不新增一套数值规则。

计算、查看与应用​

计算先生成校正证据，项目配置保持原样。结果包括碎片矩阵、响应系数、各实验验证误差、证据计数以及图表。检查哪些参数有实验证据、哪些沿用了初始值，再决定是否应用。

点击应用后，工具校验本次配置、运行参数及证据文件的 SHA-256，再原样应用这一次结果，不重新读取 WYX 或计算另一套结果。配置或产物发生变化时，应用会被拒绝；修改配置后应重新计算。应用只更新工具内的项目配置，导入时的原始文件不变。

项目、已保存配置、输入和运行历史保存在服务端。刷新或重新打开页面可以继续查看。正在运行的计算可以取消；运行失败会显示错误和日志，不会被标为校正完成。

导出​

可下载当前项目 TOML，以及每次计算的 calibration_result.toml、碎片矩阵、响应系数、验证表、图像和审计记录。校正后的 TOML 可以交给定量分析或动力学分析使用。

程序完成只说明计算按所选配置执行。验证误差、参数证据和模型是否适用于本次实验，仍需结合标准气与实验条件判断。

命令行​

原有 process_mass_calibration、plot_mass_calibration 和 fit_mass_calibration 保留。独立工具也提供命令入口：

taptap-mass-calibration-tool serve --port 8894 --workspace /path/to/experiments
taptap-mass-calibration-tool template --output calibration.toml
taptap-mass-calibration-tool inspect --config calibration.toml --project-root /path/to/experiments
taptap-mass-calibration-tool run --config calibration.toml --project-root /path/to/experiments --output results/calibration

run 返回 audit_record_sha256。apply 必须使用相同配置、项目根目录、输出目录和文件数量限制，并传入此哈希：

taptap-mass-calibration-tool apply --config calibration.toml --project-root /path/to/experiments --output results/calibration --audit-record-sha256 <hash>
taptap-mass-calibration-tool plot --config calibration.toml --output results/calibration-current.png

独立画图只展示已保存的校正，不重算、不修改配置。绘图输出应放在新的位置，避免覆盖审计已绑定的证据图。
