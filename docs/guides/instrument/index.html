仪器

分析和看数据不需要打开仪器页面。这一页是要看温度、流量、质谱，或启动一次实验时才用。

打开​

仪器控制内置于 TAP。Mac、Windows 和 Linux 使用同一套界面和配置格式；配置决定使用模拟器还是实际设备驱动。SIM 无需安装插件或启动宿主桥接，Docker 内的计算服务会直接运行模拟。

  1. 打开侧栏 Apps（应用）→ 工作台。
  2. 打开 Instrument Control，进入所属聊天右侧的工作台；已有对话也可以从工作台 + 打开仪器。
  3. 在仪器内部切换 PID、TAP、QMS 等页面，以及 Experiment config（实验配置） 和 Bench settings（仪器配置）。

页面​

页面你在这里看什么
PID温度控制
TAP采集时序、脉冲阀参数、质量表、循环次数、输出名称与手动脉冲启停
QMS质谱
Quantitative每个脉冲的基线、面积和相对值
Process Value温度、压力、进料随时间的变化
Program实验步骤
Responses当前测试的实时响应、历史脉冲、测试信息与注释笔记
Experiment config（实验配置）当前工作区的 tap.toml，支持生成、编辑、校验、保存和导出
Bench settings（仪器配置）仿真或真机的驱动、端口、采集限值和时序

Responses（响应） 一次只打开当前工作区内的一个测试 SQLite，也就是第二级测试文件；不接受汇总数据库、索引或 WYX 文件夹。手动脉冲成功启动后会自动进入此页，跟随当前测试的采集响应。切换页面仍可停止采集。

点击 选择测试，可直接填写测试文件路径，或在弹窗中按文件夹、名称检索历史测试。页面不会自动扫描并列出整个工作区。选择历史测试时显示已记录脉冲，使用脉冲选择框和分页查看其他脉冲；点击 返回当前测试 恢复实时响应。单独查看历史文件不会打开仪器连接。

展开 测试信息，可以查看所选脉冲记录的温度、压力、阀门时序、采样率和质谱参数；缺失值显示为「—」。历史图直接使用文件中的采集时间和电压，不做平均、基线扣除或增益换算。

在 注释笔记 中选择整次测试或一个已记录脉冲，编辑后点击 保存笔记。注释写入同一个 SQLite 的独立 tap_annotations 表，保留原始采集数据与格式版本。采集过程中也能保存测试笔记；切换测试或脉冲会保留未保存草稿。如果其他页面已更新同一条笔记，先比较最新保存版本，再决定保留草稿或使用已保存笔记。

这台仪器没有的部件，把对应项留空，页面会藏起那一块。

图表与布局​

响应图默认使用更大的显示区域。在图内滚动鼠标滚轮，围绕鼠标所在的纵坐标缩放 Y 轴；按住鼠标左右拖动，框选要查看的时间范围。双击图表或点击 Auto 恢复两轴自动范围，框选过程中按 Escape 可取消。

采集时实时响应每 100 毫秒检查新数据，空闲时降为每 500 毫秒；温度等趋势每秒更新，测试元信息约每 2 秒读取一次。实际曲线更新也取决于仪器的采集分段间隔，显示刷新不会改变采样率或写入 SQLite 的原始数据。慢请求尚未返回时不会叠加新的实时请求。

在仪器自己的 Bench settings → 图表 中，可以选择默认的「滚轮缩放纵轴 · 拖拽框选横轴」，或「滚轮缩放双轴 · 拖拽平移横轴」，也可以调整图表高度。这些显示偏好保存在当前浏览器，不修改仪器配置。

桌面宽屏下，对话框和工作台之间的分隔条可以左右拖动，调整两侧宽度，操作方式与左侧栏分隔条相同；两侧均保留最小可用宽度。

让 Agent 操作工作台​

保持 Instrument Control 页面打开，Agent 可以读取页面状态、共同编辑草稿，并通过页面声明的操作调整设定、启动脉冲、运行步骤或停止采集。操作经过同一套仪器服务，结果返回到对话；未确认的请求不代表已执行。未接入协作协议的普通网页不会因此获得自动控制能力。

在 TAP 的 设置 → 工作 中选择 Agent 的工作台操作模式。设置对当前 TAP 实例中的所有工作台应用生效，切换对话、工作区或应用后继续使用：

  • 逐次确认：执行前显示操作、参数和待执行草稿，可以允许这一次或拒绝。
  • 自主执行：Agent 可以直接执行已接入协作协议的页面动作。可以在「工作」设置中随时撤销；保存仪器配置、切换仪器仍需要逐次确认。

仪器页面只在有待批准操作时显示确认卡片，不再单独配置 Agent 权限。撤销权限会阻止尚未开始的操作，已开始的实验请用仪器的 Stop 停止。实时曲线刷新不影响待确认请求；执行相关参数改变后，旧请求会失效，需要重新提出。独占锁和硬件限值继续生效。这项权限控制的是工作台动作，独立 CLI 工具保留各自的授权规则。

保存 Program​

在 Program 页填写实验路径和步骤后，点击 Save 将编排写入实验配置；Load 从配置重新读取。页面草稿与文件保存分开，离开前应确认保存成功。保存本身不会启动仪器。旧程序引用当前仪器无法控制的阀、流量或背压时，先核对不支持的步骤再运行。

手动脉冲​

手动脉冲 位于 TAP 标签页内。可以在同一页设定采集时序、阀门延时与开启时间，选择质量表、输出名称并开始脉冲。TAP 使用鼠标点击图标，Responses 使用原 TAP 的波形图标。Cycles 是完整遍历质量数表的次数；填写正整数，跑完指定次数后停止；填写 0，则持续脉冲，直到点击 Stop。界面会显示连续运行及当前轮次。

运行中的手动脉冲点击 Stop 后停止序列，不再开始后续脉冲，并保留当前设定值。长周期采集会在下一次分段检查时中止。关闭仪器会话时仍会恢复配置中的安全态。Program 的次数规则不变。

TAP 页的 实验笔记 关联当前或最近一次手动测试的第二级 SQLite，可记录整次测试或一个已完成脉冲。它与 Responses 共用笔记和草稿；修改下一次输出名称不会改变笔记所属测试。编辑后点击 保存笔记，采集过程中也可以保存。新测试开始后，旧草稿保留在「此前测试的未保存笔记」中，可回到响应页继续编辑。文件被替换或其他窗口更新笔记时，会保留草稿并提示比较，不会覆盖新数据。

实验配置文件​

在 Experiment config（实验配置） 中查看和编辑当前工作区根目录的 tap.toml。这份配置供数据处理使用，包含物质与质量数、标定、碎片矩阵、反应器几何以及 Y-procedure、Knudsen 参数。

选择简单或完整模板，按 LABEL=AMU 输入物质，例如 H2=2、Ar=40，即可生成 TOML 草稿。简单模板写入仪器、标定骨架和反应器；完整模板还会写出可覆盖的处理参数。生成遵循 taptap project_config init_tap 和 tap.config 的规则，生成后先检查装置参数与标定值。

可以直接编辑 TOML、校验内容，再保存到当前工作区或导出 .toml 文件。生成草稿不会自动写入磁盘；切换仪器内部页面会保留未保存的编辑。若文件已被其他窗口或命令修改，保存会报告冲突，避免覆盖较新的版本。导出使用当前编辑内容。

仿真还是真机​

工作台中 Instrument Control 内的 Bench settings（仪器配置）：

  • TAP 选择 Simulated、minitap、Raman TAP，或配置目录中的其他仪器。保存只修改选中的配置。
  • Backend（后端） 选 sim 或 hardware。旧配置中的 windows 继续作为真机后端兼容。
  • Acquisition driver（采集驱动） 为 nidaqmx 时使用 NI 采集；none 表示只进行已配置设备的串口读写，不能启动 Pulse 或 Program。
  • Mass spectrometer（质谱） 选择这台使用的质谱。
  • Pulse output（脉冲输出） 默认每个脉冲一个 WYX。改成 SQLite 后，一次运行只写一个 .sqlite 文件。
  • Limits and timing（限值与时序） 里的上限要和这台装置相符。

sim 在各系统上运行相同实验流程，不打开串口或 DAQ，输出结构与真机相同。真机能力按配置逐项检查：串口协议可以使用 COM9 或 /dev/cu.usbserial-… 等本机路径；NI-DAQmx 还需要受支持的系统、Python 包和原生驱动。Mac 上的 NI 采集配置会明确报告不支持，不会自动切换成模拟器。LabVIEW ActiveX 仍要求 Windows。

修改后点击页面顶部的 Save bench（保存仪器配置），再打开仪器页。尚未保存的 SIM 选择会显示待保存提示，不会沿用旧真机配置的驱动故障。保存后显示实际配置的能力检查结果；能力检查不打开仪器。实际硬件访问仍通过同一个仪器会话，保留独占锁、限值和停止规则。

Docker 将仪器配置保存在本实例计算服务的持久目录 /data/service/instruments/，首次使用选择 Simulated。原生安装将配置保存在 TAP 用户数据目录的 instruments/，也可用 TAP_INSTRUMENT_CONFIG_DIR 指定配置目录。已有配置、当前选择和状态文件不会被覆盖。真机需要在实际运行仪器后端的主机安装串口或 NI 驱动并连接设备；模拟模式不要求这些驱动。

Docker 工作台连接 Windows 仪器​

在 Bench settings → Instrument connection 中选择 Windows host，可让界面继续留在 Docker 工作台，而串口、NI 驱动和采集在 Windows 本机运行。默认地址为 http://host.docker.internal:8790。主机凭据只保存在 TAP 服务端，输入框留空会保留已有凭据，不会把凭据写入工作台共享状态。

先点击 Test connection 检查 Windows 服务、串口依赖、NI 驱动版本及设备名称。该检查不打开串口，也不创建采集任务。再保存连接；切换会检查当前仪器是否闲置，实验运行时拒绝切换。保存连接后重新读取目标主机的配置，首次连接不会自动复制或覆盖另一台主机的仪器配置。打开实时仪器页才开始实际连接。

部署时需要两端共享同一个工作目录。仓库的 docker-compose.instrument-host.example.yml 提供共享目录和只读凭据挂载的覆盖文件，复制为本机 docker-compose.override.yml，在 .env 设置 TAP_WORKSPACE_HOST 和 TAP_INSTRUMENT_TOKEN_FILE。如果原来使用 Docker 命名卷，先保留并迁移原工作区文件，再切换挂载，不要删除卷。私有用户目录 .taptaptap-users 继续使用原 Linux 卷的子目录挂载，保留其权限；初始化服务只准备该目录，不读取或替换已有内容。Windows 启动脚本的 -Workspace 与 -Paths "/data/workspace=..." 必须指向该同一目录：

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/launcher/tap-plugin-bridge.ps1 `
  -Repo E:\TAP -Workspace E:\TAP\workspace -Paths '/data/workspace=E:\TAP\workspace'
docker compose up -d

启动器安装 Python 串口和 NI 接口依赖，NI 系统驱动需在 Windows 安装。Windows 仪器配置位于桥接状态目录的 instruments/，默认是仓库的 plugins/instruments/；包内模板不会被修改。可在页面中选择并保存 Raman TAP 等配置。连接失败会明确报错，不会自动改用 Linux 或模拟后端。

选择 Windows 后，聊天里的仪器操作使用同一工作台接口。单独启动的 instrument_bench、instrument_run、instrument_labview CLI 不共享该仪器会话，Docker 会拒绝新建这些 CLI 运行，避免操作另一套后端；已有 CLI 运行仍可查询状态、读日志或取消。

配置 SIM 实验​

PID 的升温速率只控制反应器。SIM 的进气管线（Feedline）默认按未加热管线处理，保持 25 °C，不随反应器升温；PID 页面、趋势和脉冲 SQLite/WYX 记录使用相同的管线温度。真机仍读取各路 PT100。

默认 Simulated 配置只提供 A/B 脉冲阀控制。进气管线阀、排气阀、辅助继电器和 VICI 只有在仪器配置中明确映射到控制器时才会出现；保存过的开关状态不会自动生成可控设备。Program 加载包含未连接控制的旧步骤时，会列出这些指令并禁止启动；确认后点击 移除不支持的控制，再检查步骤。未安装的流量和背压控制同样适用。管线的手动气路操作不会被当作软件已执行的动作。

在仪器配置的 Simulation gas lines and quartz bed（模拟气路与石英砂床） 中，分别选择 A、B 脉冲阀的气体和标定进样速率，并填写床层厚度、石英砂颗粒直径、孔隙率和曲折度。每条进气管线可设置绝对压力（mbar），每个阀选择其进气管线及标定参考压力。进样速率以 nmol/ms 表示；在管线温度固定、供气稳压和出口近似真空的条件下，实际进样量 = 标定速率 × 开阀时间 × 管线压力 / 标定参考压力。默认前两路和参考压力均为 1000 mbar，其余管线为 0；这些是示例值。SIM 显示物理压力，不伪造传感器电压。默认值用于演示，需要替换为装置参数和标定结果。床温使用 PID 页当前温度；每个阀的延时和开启时间仍在 TAP 页设置。保存后这些输入会写入当前仪器 TOML。

实时进气压力显示 mbar，新采集的 SQLite/WYX feedline_pressures_bar 字段保存 bar：1000 mbar = 1 bar。真机先按压力通道的电压标定和 unit 换算，再用于显示与存储；量程和单位必须与实际传感器一致，不能只改界面标题。缺少单位的旧接口读数显示「—」。历史 WYX 导入会原样保留压力数组，不能仅凭字段后缀确认旧文件的物理单位，应结合原采集程序和标定核对。

SIM 按每个阀注入的气体分子量计算 Knudsen 传质，再叠加它们的出口响应。质量表选择监测的 m/z，不再把 m/z 当成注入气体的分子量。支持 H₂、He、Ne、N₂、CO、O₂、Ar、CO₂、Kr 和 Xe 的指定主离子通道；N₂ 和 CO 在 m/z 28 重叠，未注入气体的通道只有背景。模型保留床层、温度、进样量对响应时间、峰形和面积的影响，不将每条曲线重新缩放到固定峰高，也不把采集窗外的尾迹补回窗内。

SIM 的质量表只编辑质量数和内标。灯丝、SEM 高压、检测器与放大器设置统一在 QMS 页控制，切换质量数不会用旧质量表覆盖它们。SEM 高压不是响应曲线的信号电压；信号由出口通量经示例电离灵敏度和仪器 A/V 换算得到。没有 SEM 高压到增益的实测标定时，不凭电压数值生成放大曲线。

当前线性惰性 Knudsen 模型中，压力改变进样量和响应峰高、面积；固定气体、床层、温度与开阀时间时，归一化峰形和峰位不随进样量改变。模型尚未包括储气管耗尽、压力恢复、气体碰撞引起的过渡流或压力相关吸附，不能据此预测这些效应。供气压力缩放采用固定标定导流能力的近似，适用范围应以阀的实测标定为准。参见 Kurt J. Lesker 导流能力说明。

这是均匀惰性填充床的前向模拟，不是对实验数据的拟合。它目前不包含吸附、催化反应、多层床、混合气配比、碎片谱或同位素分布；每次采集独立计算，不将前一周期的尾迹带入下一周期，绝对电流和电压也未经真实仪器标定。使用反应性气体选项时，仍按本模型的非反应传质假设计算。

闭阀基线采集​

阀门保持关闭的基线采集也可以保存为 WYX 或 SQLite。基线结束时不会把最后一个基线点当作缺少脉冲进样的无效记录。保存后仍需检查记录数、AMU 与完整采样曲线；SIM 验证不替代实际仪器的压力和信号标定。

一次只占一台​

网页占用仪器时，不要再开独立控制台。独立控制台的默认地址是 http://127.0.0.1:8877/。一次运行独占设备。Program 取消或关闭仪器会话后，设备回到配置里写好的安全状态；手动脉冲的 Stop 按上面的手动脉冲规则处理。

可以怎么说​

列出当前仪器里有什么，不要改任何设定。
用仿真跑这份实验步骤，输出到 rehearsal。跑完告诉我写了哪些文件。不要把后端改成实验室电脑。

真机之前，先在仪器配置里确认后端、仪器名字、限值，以及输出是 WYX 还是一个 SQLite 文件。
