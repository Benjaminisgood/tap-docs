Y 方法

Y 方法使用脉冲响应、标定与碎片矩阵、进料组成、脉冲量和反应器几何计算浓度与反应速率。动力学工具要求先完成独立基线漂移拟合，并按各条记录的采集时间、AMU 扣除拟合基线，然后再解碎片和计算 Y。不会再次扣除预触发均值，以免抵消已经应用的拟合基线；预触发区只用于估计噪声。

在动力学工具中操作​

  1. 导入反应数据与独立基线数据，在“基线处理”中明确选择基线表和记录范围，查看各 AMU 的实测点、拟合与残差后运行。
  2. 在“脉冲量”步骤选择反应数据和范围，核对气路体积、阀门对应气路及参考温度后运行。
  3. 进入“参数确认”，检查本次使用的反应文件、记录范围、基线拟合文件和脉冲量文件。这里可以直接编辑 calibration 系数和 fragmentation 矩阵，并核对内标、组成、几何与平均循环数。
  4. 选择 Base / 手动滤波 或 Pro / 自动滤波。Base 使用你明确填写的固定滤波器和参数；Pro 根据噪声与信噪比选择滤波方案，结果中保存每个通道的滤波决策。两者使用当前 SDK 实现，不直接运行实验室参考脚本。
  5. 确认参数后进入精简的 Y 运行页。参数、输入或前置结果变化后需要重新确认。最后不足一整批的循环仍会计算，并记录实际循环范围。

标定文件的查看、格式转换、检查与备份在独立的“配置文件”工具中完成，不再放在 Y 页面。配置工具保留原文件，输出可重用的 TOML、原生 CSV 和带校验记录的备份包。 每条记录是一个通道的一次采集；一个完整循环按顺序包含所选通道，不表示同步测量。处理范围的第一条和最后一条都包含。程序不会通过删掉坏记录或减少采样点来凑齐循环。

CSV 使用当前的 label,amu,coefficient 系数表，以及 observed_amu,observed_label,species_* 碎片表。实验室旧 XLSX 的物种行格式只在表头被明确识别时转换；预览会说明转置。导入保留原始文件及来源记录，不修改实验目录里的表。

核对结果​

计算完成后直接显示图表。先选物种通道和平均批次，再查看：

  • 出口响应：原始与滤波后曲线叠加，检查前沿、峰值和尾部。
  • 浓度、反应速率：保留正负值及完整时间轴。
  • 速率–浓度：按时间顺序连接同一批次的对应点，不额外拟合关系。
  • 滤波差值：原始响应减去滤波响应，用于检查滤波影响。
  • 每采样间隔积累量：原始 Y 输出的 rate × dt，不是直接测得的表面库存。

网页只读取所选通道和批次的完整曲线，下载结果仍提供全部数据。对数坐标不能表示零和负数，图中会保留这些位置的缺口并提示数量；切回线性坐标可以查看。

“入口使用相同滤波”决定入口响应是否应用与当前物种一致的滤波链。它会影响反演结果，应与滤波方法一起复核。保存的设置、每批范围和完整数据用于追溯本次处理。

LibreOffice 输出​

结果下方可将当前通道和批次的全部时间点导出为 ODS，包括出口响应、浓度、速率、每采样间隔积累量、原生可编辑图表与来源记录。图表引用单元格，负值保留，缺失值保留为空格。完整多通道、多批次 CSV 仍可下载。

点击“读取作图样式库”选择同一账号在 LibreOffice 作图样式应用中保存的字体、颜色及尺寸；“管理作图样式”在新标签打开该应用。科学坐标名称和单位取自结果文件，不被样式模板中的旧标题覆盖。

使用 CLI​

CLI 的 process_y_procedure y_procedure 使用原始测量目录、配置和对应的脉冲量表。使用独立拟合基线时设置 y_procedure.baseline_method = "fitted_drift"，并传入 --baseline-fit-csv。传统 CLI 的 pretrigger 方法仍可显式使用，但动力学工具的 Y 流程要求拟合基线。start-index / end-index 指完整循环的起止位置，结束位置不包含；它们与网页按单条记录填写的范围不同。

科学计算与绘图可以分开运行。速率、浓度、滤波检查和关联图各有专用命令。先选择需要的物种与批次，再导出少量图；图上的值应对应保存的数据，而不是为了外观重新平滑或裁掉负值。

图表正常和程序运行成功不等于科学结论已经成立。应结合采集设置、标定证据、滤波影响及未解释的残差判断。是否采用结果见 由你验收。
