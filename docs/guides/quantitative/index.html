定量

定量分析是有独立页面的工具，不依赖对话或工作台会话。页面按「导入数据 → 基线处理 → 定量分析 → 导出结果」四步组织。Knudsen 验证不再是这条流程的步骤或定量前置条件。

从导入到定量​

  1. 导入 SQLite 数据和已有 TOML 配置。支持一份文件包含多个测试，也可导入多份文件。参数可以在后续步骤中编辑。
  2. 在「基线处理」中打开「选择数据」，将用于拟合的测试设为基线。默认使用这些测试的全部记录；需要选定范围时，在同一窗口填写。测量测试不是运行基线拟合的必填项。
  3. 查看各 AMU 的基线观测值、拟合曲线和残差。进入「定量分析」后选择一项测量测试，检查标定物种、碎片矩阵、标定系数和内标，再运行。
  4. 查看三项定量结果，下载 CSV、PNG 和本次 TOML，或导出包含全部通道、循环、来源记录和三张可编辑图表的 LibreOffice ODS。ODS 可以应用「LibreOffice 作图样式」应用中保存的字体和配色。修改基线数据、记录范围或拟合参数后，需要重新拟合，旧结果仍可下载。

数据选择表在单独的窗口中打开，各步骤使用自己的角色名称。记录编号从 1 开始，包含起点和终点；基线可自由选择记录，不要求组成完整 AMU 循环。定量实验仍需完整的已标定通道循环。点击「完成选择」保存范围，页面列出实际使用的文件、表名和记录范围。

可以通过项目地址、已有分析列表、文件或处理记录重新打开分析。刷新恢复已保存的项目；登录过期时原地重新登录，保留当前页面的参数草稿和已上传文件。另一个页面修改配置后，当前页面需要重新读取并核对，不能用旧版本直接覆盖。

基线如何计算​

基线统一标为「基线」，不区分 baseline0 / baseline1，也不把选择文件的先后顺序当作实验顺序。可以选择一个或多个基线测试，不限定为两份或三份。每个 AMU 至少需要两条基线记录。

对每条选中的基线记录，程序先将完整信号换算为电流，再取整条记录的均值作为一个基线观测值。各文件中的观测值按 AMU 合并，按真实采集时间排序，拟合：

基线电流 = a × exp(-b × 距首条基线记录的天数) + c

拟合对每条记录的均值等权，不按文件等权，也不按记录中的采样点数量加权。因此，一份文件包含更多记录时，会提供更多拟合观测值。处理和绘图不抽取或丢弃采样点；图中的一个基线观测点明确对应一条完整记录的均值。

这个模型限制 a >= 0、b >= 0，衰减率 b 还受「最大基线衰减率」约束。它描述随时间衰减或近似恒定的基线，不能完整表达持续上升、突变或非单调漂移。采集时间、拟合曲线和残差需要由使用者结合实验判断；运行成功不代表模型适合本次实验。

计算测量数据时，响应先扣除该条记录自身的触发前均值再积分。基线贡献使用「测量触发前均值 − 该采集时刻的拟合空白基线」乘以记录周期。响应面积和基线贡献分别经过碎片校正与标定，总响应为两者之和。三者均保留在结果 CSV 和定量图中。

三张表均以内标的碎片校正后响应面积归一化，并使用标定系数比，单位为无量纲。它们不是物质的量、转化率或选择性。每行对应一次顺序扫描循环，不是把所有 AMU 视为同时采集，也不做循环平均。负值保留，需结合空白、噪声和标定判断。

内标只选一次​

在标定表中填写物种名称、AMU 和标定系数后，从「内标物种」选择一个物种。选项同时显示名称和 AMU，例如 Ar · m/z 40。页面会同步保存名称和 AMU，不需要重复填写两个字段。

旧 TOML 中只有名称或只有 AMU 时，页面会尝试与标定物种匹配；二者冲突或无法匹配时，需要重新选择。最终计算使用的内标必须出现在本次标定物种中。

查看和管理文件​

「我的文件」集中显示当前登录用户上传的数据、参数配置和输出结果，可以按类型筛选、搜索、下载、重新打开所属分析或删除。CSV、文本配置和 PNG/JPEG/WebP 图片可预览。上传数据与输出文件可删除；当前分析配置暂不支持单独删除。数据和结果按用户分别保存。

当前尚未启用自动清理，也未给文件设置过期时间，因此页面不会显示虚假的过期倒计时。这些目录用于分析期间暂存文件；需要保留的数据和结果请下载，使用后可手动删除。运行中使用的文件暂不能删除。

基线图用于核对观测、模型和残差；定量图用于对照相对响应、基线贡献与总响应。技术检查和程序完成状态不能替代对实验数据、标定与模型适用性的判断。核对结果后，再交给 Y 方法 或 反应结果。
