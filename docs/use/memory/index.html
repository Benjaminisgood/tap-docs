记忆

记忆放在工作区里，用来记住你怎么称呼文件、常用的内标说法、这个项目的文件夹习惯。实验结论写在你的记录和结果文件里。

它会记住什么​

普通话题里，值得下次还用的习惯可以被整理进记忆。临时聊天不写入记忆。

原始 WYX、你接受的校准和已经核对的表，不靠记忆来保存。请它做事时仍然要写出路径。记忆里的一句话如果和文件不一致，以文件为准。

整理一次​

在对话里：

命令作用
/dream整理一次当前工作区的记忆
/dream-log看上次整理改了什么
/dream-restore退回到整理前的一份

整理之前，重要结论先写进工作区里的一个文件。整理会改记忆，不会改你的 WYX。

自动整理​

Settings → System（设置 → 系统） 里可以关掉自动整理。关掉之后，已有的记忆文件还在，只是不再自动改。需要时再手动 /dream。

和压缩对话的差别​

/compact 只把这一段对话的早期内容收成摘要，方便继续聊。/dream 改的是工作区里的记忆，给以后的话题用。两件都做完，摘要和记忆里没写上的数字仍然要回到结果文件里查。

换工作区​

每个工作区有自己的记忆。换到另一个实验文件夹，不会自动带上上一个项目的习惯。这是有意的：不同实验的内标和路径不要混在一起。
