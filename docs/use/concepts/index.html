概念

这一页把后面会反复出现的词说清楚。不必记命令。

你打开它时，实际上有什么​

你在浏览器或终端里打字。这台电脑上有一份 taptaptap 在听。模型在你选定的服务里写回复。实验文件在工作区里。对话记录在工作区外面的会话目录里。

第一个窗口会把本机服务拉起来。后开的浏览器或终端接上它。最后一个这样的窗口关掉后，随开随关的服务也停下。想让它留着，看 一直开着。

配置和工作区​

配置工作区
默认位置~/.taptaptap/config.json~/.taptaptap/workspace
里面有什么模型、密钥、权限、时区实验文件、它写出的表和图、记忆
谁来改设置页。必要时用 taptaptap onboard你复制文件进去，或让它把结果写到你指定的新目录

对话记录在 ~/.taptaptap/sessions/，换工作区不会把旧对话搬进新文件夹。

终端直接启动时，工作区是你当时所在的文件夹。指定别的位置：

taptaptap --workspace /你的实验文件夹

浏览器里点输入框上方的项目名，选择文件夹或粘贴这台电脑上的绝对路径。

一轮对话​

  1. 你发送一句话，可以附上文件。
  2. 它按这句话去读工作区、做你同意的分析，或停下来问还没定的事实。
  3. 你看到回复、文件路径和异常。
  4. 你决定留下、重做，或只当作草稿。

回复进行中可以停止。停止之后，未发送的草稿会回到输入框。

浏览器、终端和后台​

两边可以看同一段对话，工作只做一次。终端有自己的全屏按键，命令见 终端。网页上的按钮见 浏览器工作台。

taptaptap serve 另开一个给其他程序用的入口，见 从其他程序调用。那不是平时看数据的网页。

提供商和模型​

提供商是持有密钥或登录的那一家。模型是这一家里具体用来回复的名字。预设把「哪一家、哪个模型」存成一个你起的名字。一段对话选用一个预设。主模型不可用时，如果预设里排了备用模型，回复里会写出这一次实际用了哪一个。

话题​

一个话题是一段持续的对话。/new 清空当前这段。终端里的 /new-chat 保留当前这段，另开一段。临时聊天不进历史。

工作台、草稿和运行​

工作台是对话旁的多标签应用区。它使用所属对话的项目与权限；从 Apps 打开应用会新建所属对话，在工作台内用 + 打开则继续使用当前对话。

名称含义
命令操作一项 CLI 任务，保存参数版本、校验问题、批准和执行状态
流程草稿定量、动力学或 DAG 的步骤、参数及依赖关系，可以由你和 Agent 共同编辑
运行快照创建运行时固定的流程版本，之后编辑草稿不会改它
标签查看和编辑这些内容的界面入口；关闭它不删除任务，也不取消运行

参数修改会更新版本，旧批准不能继续使用。缺项时任务等待填写；默认人工策略下，参数完整后仍需批准当前版本才可执行。批准只代表执行许可，结果还要由你验收。

标签布局、流程草稿和运行分别保存。刷新恢复仍打开的标签，已关闭的标签保持关闭。先确认编辑器显示已保存或已同步，再离开页面。完整步骤见 工作台与分析流程。

记忆​

记忆是工作区里它记下的习惯，例如你常用的说法。它不是实验记录。原始 WYX 和你接受的结果文件才是证据。整理记忆见 记忆。

技能和应用​

技能告诉它：做这类实验时先核对什么。应用提供可调用的程序、服务或页面。Apps 管理应用，应用页面进入工作台；Skills 在列表页自己的详情面板中开关和编辑。关着的技能不会被选用。见 应用与技能。

它能改哪些文件​

默认权限下，它处理当前项目允许的范围。完全访问才碰到项目以外的路径。

请它裁剪或重编号时，保留的内容复制到新目录，源文件留在原地。质量校准先给你证据，你接受某一次之后才改配置。

后台里的事​

一次分析或一次实验运行会在后台进行。你在页面上看到状态和结果路径。取消会停掉这一次。仪器被占用时，取消之后设备回到配置里写好的安全状态。

自动任务是「以后再做」，见 自动任务。
