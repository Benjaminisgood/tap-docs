图片

把图片发给它​

浏览器里点 Attach files（添加文件）。终端里在输入框聚焦时按 Ctrl+V 或 Alt+V，从剪贴板附上图片。

发出去之前，终端把图片显示成 [Image #n]。删掉这个占位，图片一起去掉。

这些情况会停在输入框，不会发出去：空文件、类型对不上、单张太大、一次带的太多、总大小超过限制。页面会写出原因。

附图适合指着一张已经画好的图说话。图上的数字仍以原始文件为准。

让它生成一张图​

Settings → Capabilities（设置 → 功能） 里可以配置图片生成：选择提供商、模型和默认画幅。提供商用的是你已经保存的凭据。保存后如果提示重启，重启再生效。

配置好之后，输入框可以切换到图片生成，描述你要的图。适合装置示意图、路径示意和版式。实测数字不要交给画图去编。请它画结果图时，先说明必须沿用你给出的数据。

生成的图片保存在程序的媒体目录里。设置里的保存位置是这个目录下的相对路径，已有的图片不会被搬走。

和实验作图的差别​

Y 方法、面积、扩散这些图由实验步骤写成文件，落在你指定的输出目录。那一章在 任务指南。这一页的图片生成用来画示意图，不代替那些结果文件。
