工作台与分析流程

工作台在聊天旁边显示应用、命令参数和分析流程。你和 Agent 围绕同一个对话、同一份参数继续工作，执行仍交给 TAP 的命令运行时。

打开与切换​

  1. 在聊天中确认项目路径和访问权限。
  2. 进入侧栏 Apps（应用），在「应用前端」中打开 Instrument Control、文件与 OSS、DAG 工作流 或其他已启用应用。这个入口会新建并进入一个以应用命名的对话，同时打开工作台标签。
  3. 已经在一个对话中工作时，用工作台标签栏的 + 打开其他应用。它们留在当前对话中。

侧栏没有另一个独立的工作台页面，工作台也不另设聊天框或项目路径。应用可用性和文件访问范围跟随所属对话。安装与启用见 应用与技能。

点击标签可以切换；隐藏工作台或切换标签会保留已挂载编辑器的内容。标签获得键盘焦点后，左右方向键切换，Home/End 跳到首尾，Delete 关闭当前标签。含未保存修改的标签在关闭前会提示。

同一组对话可以汇集显示成员的标签。标签上会标出所属对话；点击另一个成员的标签会切到它自己的聊天，参数、附件和项目范围仍属于原对话。

Agent 协作与操作权限​

在 设置 → 工作 中统一配置当前 TAP 实例的工作台操作权限。它适用于所有已接入协作协议的应用，切换对话、工作区或应用不会重新分配权限，重启后也会保留。

  • 逐次确认：Agent 可以读取页面状态、共同编辑草稿；执行页面动作前，在对应应用中显示操作、参数和草稿，由你允许这一次或拒绝。
  • 自主执行：Agent 可以直接执行页面声明的动作，并读取实际执行结果。保存仪器配置和切换仪器仍需确认。

统一设置不会扩大文件访问范围。每份草稿和操作仍绑定所属对话、工作区和访问模式；其他对话的请求不能在当前页面执行。撤销自主权限会阻止尚未开始的动作，已经开始的操作使用应用自己的停止按钮。

页面动作由打开的应用执行，请保持对应标签打开。尚未接入协作协议的网页只能显示内容。Agent 在浏览器对话中新建、修改或启动的命令卡片和 DAG 节点也按「工作」设置决定是否自动执行，具体规则见下文。独立 CLI 工具保留各自的授权规则。

保存与恢复​

对话、项目路径和权限模式共同决定工作台的范围。已打开的标签布局保存在服务端；刷新后恢复仍打开的标签，已关闭的标签不会因旧的待填命令重新出现。从 Apps 打开的应用对话，即使尚未发送消息，也会保存标题和所属范围。

标签恢复和内容保存是两件事。 参数和流程有各自的同步状态；先等到「已同步」或「已保存」，再刷新或离开。出现同步失败或并发冲突时，先核对最新版本，再选择采用当前版本或保留自己的草稿。

关闭标签不会取消待填、待批准或已经启动的任务。要停止执行，应在操作或运行中点击取消。关闭最后一个标签后，当前聊天回到通用助手模式，已有任务继续保留。

单条命令操作​

可以直接告诉 Agent 要做的事，也可以在聊天中发送命令形式的请求，例如：

~ taptap wyx_tables root_summary

这会打开命令工作台。聊天保留请求和「在工作台打开」入口；参数、命令预览、批准、运行及日志在工作台中查看。表单来自当前部署的 CLI 命令目录，目录未能提供的命令不会凭空生成参数。

命令操作（CommandOp）是运行时保存的一项任务。缺少路径或其他必填参数时，任务停在待填写状态，你可以继续聊天，也可以先处理独立的任务。

  1. 填写参数，等待同步完成。展开 更多参数 查看可选项。
  2. 查看 需要补充或修正，并展开 命令与执行范围 核对实际命令和项目路径。
  3. 默认人工策略下，点击 批准 v… 批准当前版本，再按界面提供的 运行 启动。
  4. 查看状态、退出码以及 查看日志 中的标准输出和错误输出；需要停止时点 取消操作。

你和 Agent 修改的是同一份版本化参数。改参会产生新版本并撤销旧批准；配置文件内容、命令合同或依赖变化也可能要求重新审查。Agent 不能代替人工批准。运行已经创建后，不能把修改直接塞进旧的执行快照。

Agent 在浏览器对话中新建、修改或启动的命令操作与 DAG 节点使用 设置 → 工作 的模式。逐次确认 等待你批准；自主执行 可以自动运行目录标记为只读或写文件的有效分析命令。仪器控制命令和风险分类未明确的命令仍需人工批准，缺项继续等待填写，后续节点等待前序成功。

切换模式会重新评估尚未启动的操作，撤销自主权限会清除旧批准并拦住待启动步骤。已启动的进程继续运行，要停止它们请使用操作或工作流的取消按钮。

升级前已排队的旧命令不自动扩大授权，在 Agent 修改或启动它们之前，继续按原策略处理。Agent 接手时会改用「工作」设置，并清除原来的批准和启动意图。独立 CLI 等入口保留 tools.taptap.operationPolicy 的既有规则，manual 需要批准，auto_read_only 自动运行只读命令，auto 自动运行有效命令。它们不通过浏览器的「工作」设置授权。

聊天新发出的命令面本身是临时展示，不等于一个持久化应用标签；进入命令运行时的任务仍独立保存。需要回来查看时，可以从原聊天入口或让 Agent 打开已有操作。服务重启会保留待填和待批准任务；无法可靠恢复的已启动运行会显示中断，应先核对输出再决定下一步。

文件与 OSS 协作​

命令或 DAG 节点输出中的文件名可以直接点击；在输出弹窗的“文件”页也可点击文件夹图标。在当前对话中会打开或复用 文件与 OSS 标签，定位文件并显示预览。若已有传输或未完成的输入，会等你完成或取消后再定位。

位置栏直接列出本机、服务器、OSS 和已添加的 NAS 等挂载目录，浏览时显示位置名称与面包屑。复制文件或当前目录时，在独立弹窗中浏览目标文件夹并确认名称，无需填写服务器绝对路径；取消不会改变主列表。详见文件与存储位置。

选中文件后，可用 存到 OSS 上传归档。选中 OSS 文件后点击 复制分享链接，得到一小时有效的下载链接；持有链接的人可在有效期内下载该文件。OSS 连接和访问权限必须可用，受限项目不能借此访问项目范围外的文件。链接不会写入对话或共享工作台状态；上传与分享都需要你点击执行。打开、定位和预览文件不会唤醒 Agent 或调用模型。

打开 文件与 OSS 后，Agent 可以读取当前来源、目录、文件列表、选中路径和文本预览，也可以填写路径草稿、打开目录、选择文件预览或刷新。你手动切换目录与选择文件时，Agent 读到的是同一份页面状态。Agent 操作依然使用当前工作区的存储权限。

列表最多向 Agent 提供前 100 项，文本预览最多提供前 16000 个字符；截断时会明确标记。目录导航和刷新先回报已请求，需继续检查页面的加载状态与错误，不能把请求成功当作内容已读完。浏览器设备文件需要你先选择；该接口不授予 Agent 访问本机任意目录、删除文件、传输数据或修改存储连接的权限。

定量分析和动力学分析​

定量分析和动力学分析已迁移为独立工具，在 Apps → 工具 中打开新的浏览器标签，不依赖工作台、对话或 DAG。工具读取 SQLite 与 TOML，按固定步骤处理并导出 CSV，使用方式见 独立分析工具。

旧的分析标签会提供前往独立工具的入口；之前保存的工作流记录仍可在 DAG 工作流中查看。需要 Agent 编排分析命令时，使用下方的 DAG 工作流和当前命令目录。

DAG 工作流​

DAG 用节点表示命令，用连线表示执行先后。它支持分支和汇合，适合将已经明确的分析步骤组织成可复用流程。

具名数据端口还能把上游产物传给下游参数：文件集合可按 *.csv 等规则筛选，多个来源按顺序合并。双击下游节点可编辑来源与文件数量要求；例如两个上游产出 2 和 3 个文件，下游列表输入会显示并接收 5 个。单文件输入必须满足单文件数量，目录与目录内文件集合分开计算。旧的普通连线仍只控制执行顺序。

Python 节点可直接读取 INPUT_FILES，无需写死上游路径。实际产物、数量和来源显示在节点中，旧目录残留文件不会进入新产物集合。数量不符或文件变化时会阻止下游并显示原因；这些检查不调用模型。完整示例与限制见仓库的 docs/dag-data-workbench.md。

  1. 打开 DAG 工作流，点 新建工作流 并命名。
  2. 双击空白画布，搜索当前命令目录。选中的命令会放在双击位置。
  3. 双击节点，在弹窗里填写名称、配置和参数，也可以查看该节点的输出；可选项在 更多参数 中。
  4. 从前序节点右侧的连接点拖到后续节点左侧，或在检查器的 前序依赖 中选择节点并点 连接。
  5. 拖动节点整理画布。画布控制按钮可以放大、缩小和适配全图；窄屏上可用适配全图查看完整分支。
  6. 点击连接，在检查器中 删除连接；点击节点可 删除节点。选中节点或连接后，也可用 Delete/Backspace 删除。产生环路的连接会被拒绝。
  7. 确认显示 已保存 · v…。流程会自动保存，也可点保存图标；同步完成后点运行图标。

运行后画布保留可编辑草稿，同时显示本次运行的状态与输出。修改草稿不会改变已经启动的运行。在版本下拉框中选择某次历史运行时，节点参数来自只读快照；点击“编辑草稿”图标返回编辑。停止图标用于取消当前运行。工具栏采用纯图标，悬停可查看用途；设置图标可以调整节点输出与弹窗显示方式。

普通依赖连线只控制执行顺序。需要传递文件时，配置具名输出端口与下游输入绑定，并检查实际文件数量和来源；也可以明确填写固定输入路径。

如果上游命令明确声明生成某个配置文件，下游填写相同路径并连接依赖，就可以在同一次运行中等待配置生成，再校验并继续。人工批准绑定该依赖和参数；产物不匹配、配置被替换或权限撤销时仍会停止等待处理。

你在对话框主动交给 Agent 的协作任务，可以在它启动的流程完成后继续处理结果。手动编辑、批准、查看输出不会单独启动模型；没有待完成的协作任务、停止协作或重启服务后保持静默。

导入与导出​

导出 保存 tap.workflow.v1 JSON，包含标题、节点、参数、位置和连线。导入 可以选择 JSON 文件或粘贴内容，始终建立新草稿；不会导入旧批准、运行回执或会话身份。导入后先检查命令是否存在、路径是否适用于当前项目，再创建运行。

结果由你验收​

工作台同步和运行成功，说明软件完成了相应协作或命令执行；它们不能替你确认基线、扩散假设、校准或动力学解释正确。批准表示允许执行当前版本，科学结果仍按 由你验收 检查。

运行快照固定参数和配置指纹，但不会复制冻结所有输入数据。保留原始文件、明确输出目录，并记录采用的配置和结果版本。
