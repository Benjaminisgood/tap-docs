对话里的命令

在输入框里输入 /。浏览器和终端都会列出当前能用的命令。方向键移动，Tab 补全，Esc 关闭。/help 列出你这一份程序当前启用的命令。

两边都能用​

命令作用
/new清空当前这段对话。其他话题还在
/stop停掉这一轮正在做的事
/compact把很长的上下文收成摘要，然后继续
/status看运行状态、当前模型和连接
/model列出预设。/model 名字 换到该预设
/history最近的消息。/history 20 指定条数
/goal 你的目标把后面这件事当成要持续做完的目标
/skill列出当前启用的技能
/dream整理一次工作区记忆
/dream-log看上次整理改了什么
/dream-restore把记忆退回到整理前
/trigger 名字给这段对话登记一个本地触发名
/restart重新启动程序
/pairing查看、同意、拒绝或取消聊天平台配对
/help列出命令

只输入 /goal 会看到用法，目标要写在命令后面。只用浏览器和终端时，不必使用 /pairing。

终端里另外这些​

命令作用
/sessions搜索并切换已保存的对话
/new-chat保留当前这段，另开一段
/context说明下一轮会带上哪些已有内容
/usage打开用量图
/diff查看上一轮改过的文件
/branch从一条已完成的回复分出新对话
/detach关闭终端画面，让已经开始的工作继续
/exit关闭终端画面

/new 重置你正在看的这段。/new-chat 把这段留着，另外开始。

输入 @​

@ 用来提到一个已安装的本地应用、一个 MCP 服务，或一段过去的对话。选中之后，这句话会带上那个对象。

启动程序本身的命令，例如 taptaptap webui，在 命令行。
