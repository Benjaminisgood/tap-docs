应用与技能

应用提供可调用的程序或可操作的页面；技能告诉 Agent 什么时候、按什么步骤使用这些能力。两者都可以在浏览器侧栏找到。

Apps 管理应用，工作台显示已接入的页面​

侧栏 Apps（应用） 用于查看可用应用、安装或卸载、启用或停用，以及配置连接和授权。根据应用类型，这里可能列出 CLI 程序、Agent 插件、MCP 服务和应用前端；不是每项都有页面。

已经接入工作台的应用通过 打开 进入 工作台。从 Apps 列表打开会创建并进入新的所属对话，以应用显示名称作为标题；在已有工作台内用 + 打开，则沿用当前对话。页面中的文件路径和访问权限跟随所属对话。

工具 列表中的独立程序在新浏览器标签打开自己的页面。WYX 转 SQLite、定量分析和动力学分析各有独立页面，可以分别部署给其他使用者，不依赖聊天、工作台或 DAG。

设备连接、LAN Transfer、Syncthing 与 Tailscale 的管理入口已迁至门户 Linkhub，不再出现在 TAP 应用列表中。旧传输中心地址会跳转到门户；运行 taptap-transfer ui 可查看当前门户地址。Syncthing 原生 GUI 仍作为后端服务保留在 /tools/syncthing/，供门户连接。打开前需要在 Agent 容器里启动 Syncthing，并使 GUI 在容器端口 8384 上可被 tool-ingress 访问；守护进程没起来时，这个地址返回代理错误。它使用 Syncthing 自身的登录与 CSRF 保护。

WYX 转 SQLite 支持单个脉冲、一次测试和多次测试三种范围，在浏览器内生成 SQLite 并保留全部采样点与原始文件头。定量分析和动力学分析读取 SQLite 与 TOML，按固定步骤处理并导出 CSV。输入、结果与独立部署说明见 独立分析工具。

MCP 仍在 Apps 的 MCP 列表里配置，不作为工作台页面，也不作为这种新标签工具。

工作台入口用途
DAG 工作流编辑自定义命令节点、分支和执行依赖
文件与 OSS浏览本地文件和 OSS，下载完整工作副本或上传结果
Instrument Control内置仪器工作台，SIM 可直接运行；真机按配置连接设备
Paper2Agent Literature / Papis在所属项目内使用文献应用

具体列表以当前部署和已启用应用为准。启用页面不会替你完成仪器连接、外部服务授权或科学参数核对。

应用中的 带入聊天 会把上下文添加到输入框，由你发送。共同编辑能力取决于该应用是否接入工作台的协作接口。独立工具页面在新标签里运行，不进入所属对话；它们不显示返回 TAP 的导航。

文件与 OSS​

从工作台打开 文件与 OSS → 管理位置 添加连接。云端数据要先下载为完整工作副本，处理结果再手动上传。连接、传输回执和权限说明见 OSS 存储。

Papis 文献库​

在侧栏 Apps（应用） 中安装并启用 Papis，再从应用入口打开工作台标签。Docker 版本已预装，启用后即可使用；停用会关闭页面服务。独立服务地址仍为兼容入口，日常操作从工作台进入。

页面支持添加 PDF 或书目信息、检索文献、查看标签、编辑元数据和笔记。也可以让 Agent 添加本地文件、检索文献，或导出 BibTeX、JSON、YAML；Agent 根据当前命令目录调用可用能力。

文献保存在所属项目的 papis/library/，采用 Papis 的 info.yaml 与附件格式。添加本地附件会保留原文件；停用或卸载插件保留文献库。这个库与已有的全局 Papis 配置独立。

Skillshub​

Skillshub = 门户技能库（公开 + 我的）+ 下载到 agent custom。 技能页顶部依次是 已安装 / Skillshub / 第三方市场。点击中间的 Skillshub，直接在当前页浏览、预览和下载，不会打开新标签页。

库中列出 公开 技能与 我的 技能，可以按来源筛选或搜索名称和用途。公开库由实验室维护；我的库属于当前门户账号，和已安装到 agent 的副本分开。门户文件管理的 我的 Skillshub 区域可创建技能目录、上传 SKILL.md、脚本和参考文件。TAP 只读取门户为当前实例挂载的库，不接受其他账号 ID。

选择技能后预览正文，点击下载将整个目录复制到当前 agent 工作区的 skills/<name>/，包括脚本和参考资料。公开库与我的库可以存在同名技能，下载使用选中的来源；工作区已有同名目录时不会覆盖。下载成功后回到 已安装，可直接打开原有详情编辑器。

下载后的技能与已有 workspace skills 一样，可以查看、编辑 SKILL.md、启用、停用和删除。编辑本机副本不会修改库，删除也只移除本机副本。工作区 skills/ 中已有的技能不需要重新下载。

独立工具 /tools/skills/ 保留作为兼容入口，提供本机新建与编辑功能。点 新技能 可以在当前工作区新建 SKILL.md。名称使用小写字母、数字和单个连字符，最长 64 个字符；文件头必须包含同名 name 和用途说明 description。来源筛选只决定从哪个库下载，不是私人/公开协作编辑权限开关。

编辑时会核对文件版本，遇到冲突保留当前草稿。保存后可以在对话中用 $技能名称 调用。目录配置和 API 见 Skillshub 运维说明。第三方市场 中的 skillhub.cn / skills.sh 保留原有功能，与内部 Skillshub 分开。

Skills 查看和编辑说明​

侧栏 Skills（技能） 的 Installed（已安装） 列表支持按名字或说明搜索，以及按启用状态筛选。点击技能会在当前页面打开详情面板，不新建对话，也不打开工作台标签。

详情中可以查看来源、可用状态、依赖和说明，并切换是否使用该技能。可编辑的技能显示 SKILL.md 文本框；修改后点 保存 才写入文件，放弃修改 回到已读取内容，从文件重新加载 获取最新文件。只读技能只显示原文。

若其他窗口已经改过文件，保存会报冲突；先保留需要的草稿，重新读取并核对后再保存。离开详情前完成保存，不要把关闭面板当作保存。

Needs setup（需要设置） 表示依赖未满足，可能是缺少程序或环境变量。按详情补齐后点 Check again（重新检查）。技能文件本身不会安装科学后端，也不会证明外部设备已经可用。

更多内置任务、外部技能安装和删除规则见 技能参考。自动任务则决定什么时候再做，见 自动任务。
