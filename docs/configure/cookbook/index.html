常见接法

每种接法都做完 提供商和模型 里的保存，然后发一句「你好」。一次只配一家。

网页里填密钥​

适合大多数托管服务。在 Configure providers（配置提供商） 里找到那一家，粘贴密钥，保存，再新建预设并选择这家提供的模型名字。

模型名字以这家当前的列表为准。设置页列出来的名字可以直接选。列表暂时不可用时，页面会说明用的是缓存或内置列表。

公司或自建地址​

提供商选 Custom（自定义），或你实际使用的那一家。

  • API key 按对方要求填写。对方不需要密钥时，按页面说明留空。
  • API base 填对方给你的地址，通常以 /v1 结尾。
  • 预设里的模型名字必须是这个地址能接受的名字。

保存后发「你好」。401 表示密钥不被这个地址接受。找不到模型，表示名字不是这个地址提供的。

本机 Ollama​

提供商选 Ollama。它在本机运行，一般不要云端密钥，要本机服务已经启动。地址留空时用它的默认本机地址；你改过端口时，把地址填进 API base。

预设里的模型名字是你已经在 Ollama 里拉取的那个名字。taptaptap 不会替你下载模型。

vLLM、LM Studio 以及其他本机的 OpenAI 兼容服务，同样是：服务先在本机开着，再把地址和模型名字填进对应的提供商。

用登录而不是粘贴密钥​

OpenAI Codex、xAI Grok、GitHub Copilot 这一类在提供商页点登录，按浏览器里的步骤完成。登录状态留在这台电脑上。页面要你粘贴回调地址或授权码时，粘贴整段它让你复制的内容。

登出用设置页的注销，或 taptaptap provider logout。

配完之后​

taptaptap status
taptaptap agent -m "你好"

status 就绪但「你好」失败时，看 遇到问题 里的模型和密钥一行。不要同时改地址和模型名字。
