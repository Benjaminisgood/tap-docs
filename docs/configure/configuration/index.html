配置

能在设置页完成的，就在设置页完成。~/.taptaptap/config.json 是这些选择保存的位置。手册里如果出现片段，是要合并进去的一小段，不是拿来整份覆盖的文件。

第一次生成这个文件：

taptaptap onboard

保留已有内容并补上新字段：

taptaptap onboard --refresh

逐项问答：

taptaptap onboard --wizard

设置在哪一页​

你要改的去哪
当前模型、用量Settings → Overview（概览），模型本身在 Models
密钥和登录Configure providers（配置提供商）
预设、备用模型、上下文长度Settings → Models
浅色、深色、过程默认展开多少Settings → Appearance（外观）
界面语言侧栏 Language（语言）。记在这台浏览器里
默认工作区、默认权限、时区Settings → System（系统）
阿里云 OSS 连接、凭据、只读访问文件与 OSS → 管理位置，详见 OSS 存储
仪器控制等应用插件Settings → Apps（应用）。只在实验室 Windows 电脑上能安装和启用，改完要重启
minitap 或 Raman TAP、仿真或真机、限值侧栏 Bench settings（仪器配置）。先启用仪器控制插件
技能侧栏 Skills
自动任务侧栏 Automations
图片生成、语音、网页搜索Settings → Capabilities（功能）
聊天平台Settings → Channels
版本和配置文件路径Settings → About（关于）

Advanced（高级） 里的项搜索之后才会改。不确定时保持原样。

改完显示等待重启的，重启前页面仍是旧行为。

密钥放哪里​

密钥放在提供商设置里。对话、截图和发给别人的排错记录里不要出现密钥。

有的提供商也认环境变量。变量要在启动 taptaptap 的那个环境里已经存在。taptaptap status 用来看这家是否已经被认成已配置，它不会把密钥打出来。

工作区和权限​

Default workspace（默认工作区） 是新对话没另选文件夹时用的位置。已经打开的对话仍用它启动时的文件夹。

Default access（默认权限） 是某个项目没有单独设置时用的权限。输入框上方可以临时改成 Full Access（完全访问权限）。分析已经放进工作区的 WYX，用默认权限即可。

和实验项目的关系​

仪器端口、限值和质谱写在所选 TAP 的仪器配置里，由仪器设置页保存。实验步骤写在实验文件里。两者不要混进同一句没有路径的聊天里碰运气。打开仪器页的步骤在 仪器。
